# 高级咨询风信息图模板

用于商务、战略、运营、市场与学术分析场景中的咨询分析页、方法论图、流程图和矩阵图。只处理信息图，不套用封面逻辑。

## 生成前规划

在内部完成以下步骤，不输出分析过程：

1. 提炼一个核心结论，让所有模块围绕它展开。
2. 将长主题拆成三层文字：2–8 字主视觉核心词、完整标题、1–3 个极简英文标签。
3. 根据主题只选择一个主隐喻，并据此组织 3–6 个模块。
4. 明确一条阅读路径：从左到右、从上到下、问题到方案、输入到输出、现状到机会，或机制到结果。
5. 写出 1–3 条底部关键结论或行动建议。
6. 检查图形是否承载分析关系；去掉装饰后，核心结构仍须成立。

## 主结构选择

| 主题关系 | 主结构或隐喻 |
| --- | --- |
| 筛选、转化、销售流程、机会识别 | 漏斗 |
| 战略推进、方法论、行动计划、转型 | 路径 |
| 能力进阶、成熟度、价值提升 | 阶梯 |
| 定位、比较、竞争格局、优先级 | 矩阵或坐标 |
| 增长循环、复利、网络效应 | 飞轮 |
| 系统协同、组织连接、技术架构 | 节点网络 |
| 信息流、自动化、输入输出 | 数据流 |
| 风险控制、准入、阶段关口 | 门槛或防线 |
| 市场机会、趋势入口 | 窗口 |
| 结构变化、产业转折、认知差距 | 断层 |
| 方向选择、长期定位 | 罗盘 |
| 组织架构、能力底座、治理框架 | 建筑结构 |

不要在一页中堆叠多个互不相干的隐喻。

## 标题重构规则

- A 层“主视觉核心词”：从主题提取 2–8 个中文字或 1–4 个英文词，保持可读，并与主结构融合。
- B 层“完整标题”：在顶部信息栏完整保留用户主题，字号较小，不抢主结构。
- C 层“极简标签”：从 `STRATEGY`、`MARKET INSIGHT`、`BUSINESS MODEL`、`OPERATING MODEL`、`GROWTH SYSTEM`、`TRANSFORMATION`、`INDUSTRY VIEW`、`INFOGRAPHIC` 中选择 1–3 个真正相关的标签。

让主视觉文字成为结构的一部分，例如路径穿过字形、矩阵成为文字骨架、阶梯托起核心词、节点连接笔画。不能只在普通标题旁边摆一个图标，也不能牺牲标题可读性。

## 最终提示词模板

将所有方括号替换为具体内容，并删除未使用的说明：

```text
请设计一张高级中文商业信息图，用于“[用途：咨询分析页/方法论图/流程图/矩阵图]”，主题为“[完整主题]”。目标受众是[受众]，核心结论是“[一句话结论]”。

【视觉定位】
- 顶级管理咨询公司报告水准：理性、克制、专业、稳定、结构化，具有现代瑞士网格与高端商业编辑设计气质。
- 文字主导，视觉隐喻与分析结构深度融合；不是普通 PPT 模板，不是数据看板，不是自媒体海报。
- 白色为主背景，深蓝、黑色、冷灰和浅灰为主色；只用极少量[蓝/橙/绿/红]标记[关键节点/风险点/价值点/决策点]。
- 现代清晰的中文无衬线字体，英文标签采用克制的 Swiss-style sans-serif 气质；精准细线、极简网格、小型编号、细边框，可加入极轻纸张纹理或印刷颗粒。
- 画幅比例：[比例]；高清输出，适合[使用场景]。

【三层标题系统】
- A 层主视觉核心词：“[2–8 字核心词]”。将文字设计为[路径化/矩阵化/阶梯化/节点化/数据化等]结构，并与主隐喻融合，但必须保持清晰可读。
- B 层完整标题：“[完整主题]”，置于顶部信息栏，小于主视觉核心词。
- C 层标签：[1–3 个相关英文标签]，作为页眉或边缘编号系统的一部分。
- 副标题：“[简短副标题，可无]”。

【阅读路径与核心结构】
- 阅读路径：[从左到右/从上到下/问题到方案/输入到输出/现状到机会/机制到结果]。
- 唯一主隐喻：[漏斗/路径/阶梯/矩阵/坐标/飞轮/节点网络/数据流/门槛/窗口/防线/断层/罗盘/建筑结构]。
- 中央结构图：[具体描述结构、节点名称、箭头方向、层级或坐标轴，不能只写结构类型]。
- 让图形从主视觉文字中生长或穿过文字，使“标题本身就是分析结构”。

【信息模块】
围绕核心结论安排 [3–6] 个模块，每个模块只包含短标题、1 句关键判断和必要的数据或标签：

01｜[模块标题]
关键判断：[简短结论]
结构元素：[节点/变量/数据/关系]

[以相同格式写出其余 2–5 个模块]

【辅助分析区】
- 左右辅助模块：[关键洞察、变量、约束、机会或风险的具体内容；最多 1–2 个小结构]。
- 图例与注释：[确有必要的单位、口径、来源或编号说明]。

【底部结论区】
01 [关键结论或行动建议]
02 [关键结论或行动建议]
[最多 3 条]

【信息密度】
- 保持 3–6 个主要模块、1 个核心大结构、最多 1–2 个辅助小结构。
- 每个模块文字简短，层级分明，信息丰富但不拥挤。
- 数据、文字、图形必须具有明确逻辑关系；没有可靠数据时不要虚构数字。

【严格禁止】
- 禁止图标堆砌、装饰性插画、商务小人、握手图标、卡通人物、机器人头像。
- 禁止蓝紫霓虹、赛博朋克光效、彩虹色、花哨渐变、高饱和广告色和大面积暖色背景。
- 禁止随机模块拼贴、大段文字、复杂到无法一眼理解、普通 PPT 模板感或廉价自媒体感。
- 禁止普通大标题、视觉隐喻与文字割裂、主标题不可读、字体过粗过花、画面过满。
- 严格保证中文、品牌名、人名、术语和英文大小写正确，无乱码、无错字、无水印、无伪二维码。

最终成图必须主题清晰、阅读路径明确、图文融合、丰富而有秩序；即使去掉大部分装饰，核心分析结构仍然成立。只生成最终画面，不呈现分析过程。
```

## 输出检查

- 已写出一个核心结论，并让全部模块围绕它展开。
- 已选择且只选择一个主隐喻。
- 主视觉核心词、完整标题和英文标签形成三层系统。
- 包含 3–6 个模块、一个核心结构和 1–3 条结论。
- 所有占位符已替换，未虚构用户没有提供或无法核验的数据。
- 配色克制、阅读路径清晰、文字可读，且不存在普通 PPT 模板感。
