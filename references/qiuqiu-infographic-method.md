# 秋秋信息图制作方法

## 核心原则

信息图不是把长文缩小后放进图片，而是把知识关系变成一眼能理解、之后能复习的视觉结构。制作顺序固定为：内容范围 → 知识骨架 → 视觉编码 → 页面布局 → 质量检查。

## 五步工作流

### 1. 限定学习目标

根据主题推断或确认：

- 目标读者的知识水平；
- 单页只解决的一个核心问题；
- 读完后应该能够解释、区分或完成什么。

主题过大时缩小范围。例如“人工智能”可收敛为“零基础理解生成式 AI 的工作流程”。

### 2. 搭建知识骨架

优先保留 4–7 个核心模块。不同主题使用不同骨架：

- 概念型：定义 → 组成 → 原理 → 应用 → 误区；
- 流程型：目标 → 输入 → 步骤 → 输出 → 检查；
- 对比型：共同点 → 关键维度 → 差异 → 选择场景；
- 系统型：整体 → 子系统 → 相互关系 → 反馈回路；
- 历史型：背景 → 转折点 → 影响 → 当代意义。

### 3. 匹配视觉表达

按关系选择图形：

| 知识关系 | 首选表达 |
| --- | --- |
| 先后步骤 | 流程图、编号箭头 |
| 因果与影响 | 因果链、汇聚或分叉箭头 |
| 分类与层级 | 树状图、模块组、网络图 |
| 多项对比 | 表格、矩阵、双栏卡片 |
| 构造与位置 | 标注式示意图 |
| 要点与提醒 | 图标卡片、勾选清单 |

每个模块选择最适合的一种主表达即可，不要求同时塞入流程图、表格和示意图。

### 4. 装入版式

先安排大区域，再安排模块。每个区域只承担一个明确任务。保持阅读顺序稳定、模块边界清楚、留白充足，避免过度装饰。

### 5. 质量检查

检查四件事：

1. 内容是否准确且没有无依据细节；
2. 标题、问题、正文、总结是否互相对应；
3. 图形是否真的解释关系；
4. A4 页面上的正文是否仍适合打印阅读。

## 用户输入不足时

默认值为：零基础中文读者、学习与复习用途、一页信息图、清爽教材风。仅当受众或范围会让内容产生明显分歧时，才向用户提一个最关键的问题。
